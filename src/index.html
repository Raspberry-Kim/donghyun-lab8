데스크톱 전용 동현둠은 실제 키보드로만 움직인다. 휴대폰과 태블릿에서는 게임을 띄우지 않는다. 코드를 실행해 출전 설정을 확인하고 문서를 읽을 수는 있다.

SORTIE PROTOCOL

동현둠 규약

정하는 것은 여섯 숫자다

동현랭 코드가 출력한 정수 여섯 개를 차례로 읽는다.

순서값범위기본
1스테이지 E1Mn1–91
2난이도1–53
3체력1–200100
4방어구0–2000
5IDDQD 무적0 끔 · 1 켬0
6IDKFA 무기·열쇠0 끔 · 1 켬0
  • 아무것도 출력하지 않으면 기본값 1 3 100 0 0 0으로 나선다.
  • 정수가 여섯 개가 아니거나 범위를 벗어나면 출전하지 않고 오류를 알려 준다.
  • 난이도 1–5는 원작의 I'm too young to die · Hey, not too rough · Hurt me plenty · Ultra-Violence · Nightmare!이다.

예제

01 · 기본은 1 3 100 0 0 0을 출력한다. 0은 도옹ㅠ, 100은 도오오오오오오오오옹 도오오오오오오오오옹(10×10)으로 쓴다. 06 · 계산해서 정하기는 체력을 스테이지 × 25로 계산한다.

값이 듣는 때

  • 체력·방어구는 처음 나설 때와 쓰러져 다시 시작할 때 코드 값으로 정해진다. 다음 맵으로 넘어가면 원작처럼 이어진다.
  • 방어구가 100 이하이면 초록 방어구(피해의 1/3을 막음), 100을 넘으면 파란 방어구(1/2을 막음)로 친다.
  • 무기 6종(주먹·전기톱·권총·산탄총·기관총·로켓 발사기)은 맵이 시작될 때마다 늘 쥐어 준다. 탄약이 모자라면 총알 100 · 산탄 20 · 로켓 10까지 채운다.
  • IDDQD를 켜면 맵마다 무적이 켜진다. 체력은 코드 값 그대로다.
  • IDKFA를 켜면 맵마다 열쇠 셋, 탄약 가득, 파란 방어구 200을 받는다. 방어구 값보다 IDKFA가 앞선다.

게임 중 치트 입력은 없다

원작처럼 게임 중에 IDDQD·IDKFA·IDCLEV 같은 글자를 쳐도 듣지 않는다. 치트는 동현랭 코드로만 켠다. 원작은 Nightmare!에서 치트를 막지만, 코드로 켜는 치트는 이 난이도에서도 듣는다.

무료판에는 플라스마 라이플과 BFG9000이 없다. 그래서 IDKFA를 켜도 쓸 수 있는 무기는 6종이다.

휴대폰·태블릿은 지원하지 않는다. 화면 단추나 터치 조작이 없어 실제 키보드가 있는 컴퓨터에서만 싸울 수 있다. 마우스는 쓰지 않는다. 게임 화면을 한 번 누르면 키보드가 게임으로 가고, 위 띠의 표시가 「키보드: 게임」으로 바뀐다. 코드 칸을 누르면 다시 코드로 돌아온다.

소리는 효과음만 난다. 브라우저에서 음악 장치(OPL) 초기화가 멈추는 문제가 있어 음악은 껐다.

ENGINE & CREDITS

엔진과 출처

엔진: Chocolate Doom · doom-wasm

게임 엔진은 Cloudflare의 doom-wasm이다. 원작 둠 1.9의 동작을 충실히 따르는 Chocolate Doom을 브라우저(WebAssembly)로 옮긴 것이고, 바탕은 id Software가 공개한 둠 소스 코드다. 모두 GNU GPL 2.0이다.

동현둠은 엔진을 네 곳 고쳤다. 동현랭 값을 받는 명령줄 인자(-dhhealth -dharmor -dhgod -dhkfa), 맵마다 무기 6종 주기, 게임 중 치트 입력 끄기(자동 지도 IDDT 포함), 빌드 설정이다. 고친 소스 전체와 고친 부분(engine/donghyun-doom.patch), 빌드 방법(engine/build.sh)을 저장소에 함께 둔다.

게임 자료: DOOM1.WAD

맵·그림·소리는 둠 무료판(shareware) v1.9의 DOOM1.WAD다. © 1994 id Software. 고치지 않은 원래 파일(MD5 f0cefca49926d00903cf57551d901abe)을 그대로 함께 둔다. 무료판 파일은 고치지 않으면 자유롭게 나눌 수 있다(Debian 저작권 파일의 John Carmack 회신, Raphael Quinet). 이 파일은 GPL이 아니며 id Software의 사용 허락을 따른다. 돈을 받고 나눌 수 없다.

권리

DOOM은 id Software(ZeniMax Media)의 상표다. 동현둠은 id Software·ZeniMax·Bethesda·Microsoft·Cloudflare와 관계가 없고 승인도 받지 않은 비상업 취미 작품이다.

동현둠이 만든 것

화면, 동현랭 출전 규약, 예제, 문서, 엔진 수정. 엔진과 함께 나가므로 저장소 전체는 GPL 2.0을 따른다. 동현랭 실행기(donghyun.js)는 동현랭 v1.53을 고치지 않고 썼으며 MIT 라이선스다.
